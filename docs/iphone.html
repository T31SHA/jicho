iPhone companion

Stay connected to your desktop

Pair an iPhone with JichoBot on the desktop to view agent activity, answer questions, and receive supported Live Activity updates. CloudKit, push delivery, signing, and a configured relay are needed for remote features.

Build the iPhone target from the generated Xcode project. Device signing and CloudKit setup are documented as manual requirements in STATUS.md.
