Troubleshooting and help

Start with the platform guide and the verification status. For a bug report, include the operating system, app version, relevant integration, and a short reproduction. Remove tokens, private paths, and message content before sharing logs.

Use the issue tracker for project questions and defects. Do not attach credentials, agent configuration files, or private conversations.
