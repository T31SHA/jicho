Android companion

Pair over your local network

The Android app pairs with a JichoBot desktop on the same network. It provides agent status, remote approval and question flows, and home screen widgets. An optional relay supports remote delivery.

The Android source and license are in the repository. Build and device checks are listed in STATUS.md.
