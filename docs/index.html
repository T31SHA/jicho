JichoBot

A desktop companion for coding agents

Kito mirrors agent activity and keeps approval requests close at hand. JichoBot includes desktop apps for macOS, Windows, and Linux, plus companion apps for iPhone and Android.

The repository records the build and test status for each platform. Pairing and integrations require local setup and may depend on operating-system permissions.
