Android companion

Your agents, on the phone you already carry

JichoBot for Android shows live agent status, supported approvals and questions, and home screen widgets. The connected service keeps a quiet status notification up to date while agents work. Approval requests can vibrate; completion and failure alerts are optional and quiet.

Install and connect

  1. Download the signed APK from the homepage downloads when one is published. Android 11 or later is required.
  2. On the desktop, open Settings → Android phone, turn on Phone link, and show the pairing code.
  3. On Android, scan the QR code or open the copied pairing link. Confirm the computer; both devices need to be on the same Wi-Fi.

Check GitHub releases or read the Android build notes. Remote access needs the optional relay.
