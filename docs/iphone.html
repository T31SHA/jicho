iPhone companion

Your Mac’s agent activity, synced through iCloud

The iPhone app shows Mac sessions, approval and question requests, widgets, and supported Live Activities. Use the same Apple Account on the Mac and iPhone, then open both apps; there is no QR code or numeric passcode. Notifications require permission, and remote Live Activity delivery needs Apple signing, CloudKit, APNs, and the optional relay.

Not available as a public install yet

The source is in the repository, but there is no App Store or TestFlight release. Building for a device requires an Apple Developer account, a configured JichoBot iCloud container, and signing.
