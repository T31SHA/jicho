# Jicho

The eye on your coding agents. Approve Claude Code permission requests from a small on-screen bot or your phone. Free, MIT, no API calls.

Status: early. Core and tests exist; overlay, installer and phone approvals are being built.

    npm install
    npm test        # concurrency + correctness harness
    npm run core    # dev server; type "a" or "d" to answer the oldest request
